The Virtual Token page lets you set up an additional layer of security for authenticating your transactions.

  <img src="/images/web-portal/virtual-token/virtual-token-1.png" alt="Virtual Token page with a description of enrollment and Enrol for Virtual Token and Deactivate Token buttons" />
</Frame>

## Enrolling

Select **Enrol for Virtual Token**. An enrollment ID will be generated and sent to your registered email address.

## Deactivating

Select **Deactivate Token** to turn off virtual token authentication for your account.
