The Transactions page shows a full history of activity across your accounts, with running totals for volume, inflow, and outflow.

## Summary cards

| Card | Shows |
|---|---|
| **Total Volume** | Combined value of all transactions |
| **Total Inflow** | All-time credits |
| **Total Outflow** | All-time debits |

## Transaction history table

Each row shows the Transaction Date, Account Number, Account Name, Transaction Reference, Amount, and a **D/C** indicator marking whether the entry is a Debit or Credit. The table is paginated, showing a set number of transactions per page.
