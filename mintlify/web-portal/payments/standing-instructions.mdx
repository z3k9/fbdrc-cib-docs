Standing Instructions automate a recurring transfer to a specific beneficiary on a set schedule.

</Frame>

## Creating a standing instruction

<Steps>
  <Step title="Select Source Account">
    The available balance is shown once selected.
  </Step>
  <Step title="Enter Beneficiary Details">
    Provide the **Beneficiary Account Number** (use **Lookup** to verify) and confirm the **Beneficiary Name**.
  </Step>
  <Step title="Set Amount and Schedule">
    Enter the **Amount**, then set the **Frequency** (e.g. Monthly), **Day of Month**, and **Hour** the transfer should run.
  </Step>
  <Step title="Set Start and Expiry Dates">
    Define when the standing instruction begins and ends.
  </Step>
  <Step title="Submit">
    Select **New Standing Instruction** to create it.
  </Step>
</Steps>

## Standing instructions list

Once created, each instruction appears in a table showing From Account, To Account, Amount, Frequency, Start Date, and Status (e.g. Pending).
